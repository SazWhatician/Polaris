## Ponytail Protocol (Minimalism & YAGNI)

1. **Does this need to exist?** Skip unneeded or speculative code.
2. **Already in codebase?** Reuse existing patterns and utility functions.
3. **Standard Library / Native Feature?** Prefer standard library and native browser/platform features over adding new dependencies.
4. **Minimal Diff & Zero Slop:** Write the shortest code that works safely while keeping security, validation, and error handling intact.
